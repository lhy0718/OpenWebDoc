# Code of Conduct

OpenWebDoc welcomes constructive, evidence-based collaboration.

Participants are expected to:

- be respectful and specific when giving feedback
- focus criticism on code, documents, tests, and user outcomes
- avoid harassment, personal attacks, or discriminatory language
- avoid sharing private documents, secrets, or sensitive personal information
- report security issues through the security policy rather than public exploit
  details

Maintainers may close, hide, or moderate issues and pull requests that violate
these expectations or put users at risk.
